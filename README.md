# Movie Swipe App

An interactive movie recommendation application built with vanilla JavaScript and Tailwind CSS.

The app helps users discover movies based on their preferences using a swipe-inspired interface and a custom recommendation algorithm.

## Features

- Interactive movie discovery
- Like and dislike movie preferences
- Personalized movie recommendations
- Custom recommendation scoring algorithm
- Movie filtering and sorting
- Responsive user interface

## Technologies

- HTML5
- CSS3
- JavaScript (ES6+)
- Tailwind CSS
- JSON

## How It Works

The application uses a local JSON dataset containing movie information.

User preferences are evaluated by a custom JavaScript scoring algorithm, which ranks movies and selects recommendations based on their scores.

Movies that have already been disliked are excluded from future recommendations.

## Getting Started

1. Clone the repository.
2. Install dependencies:

   npm install

3. Open index.html using a local development server, such as VS Code Live Server.
